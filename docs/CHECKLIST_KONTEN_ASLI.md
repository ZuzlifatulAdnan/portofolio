## 5. Tambahan profesional

- Testimoni dari klien yang memberikan izin tertulis.
- Kontribusi open-source dan GitHub pinned repositories.
- Artikel blog/tutorial atau catatan teknis.
- Penghargaan atau presentasi di acara resmi (jika ada bukti).
- Bahasa yang dikuasai dan tingkat kemahiran yang realistis.
- Alur kerja (discovery → desain → implementasi → tes → deploy → maintenance).
- Ketersediaan kerja sama & opsi CTA: “Hire Me”, “Discuss a Project”, atau “Download CV”.

## 6. Checklist sebelum tayang

- [ ] Seluruh informasi benar, dan semua screenshot memiliki hak publikasi.
- [ ] Tidak ada data rahasia (IP internal, password, token, identitas sensitif, konfigurasi rahasia).
- [ ] Konten Indonesia dan English sudah diperiksa tata bahasa.
- [ ] Semua URL aktif dan menuju akun resmi Anda.
- [ ] Nomor sertifikasi dan masa berlaku sudah divalidasi.
- [ ] Server telah mengaktifkan HTTPS, backup, dan review keamanan.
- [ ] Tampilan desktop/tablet/mobile lolos pemeriksaan.
